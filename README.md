SyharikPlay
===========

Мини‑сайт с набором классических мини‑игр (синглплеер, без бэкенда).

Текущий стек и структура
------------------------

- **Стек**: чистые `HTML`, `CSS`, `JavaScript` без сборщика.
- **Графика**: `HTML5 Canvas` для всех игр.
- **Файлы**:
  - `index.html` — посадочная страница и список игр.
  - `game.html` — полноэкранный режим выбранной игры.
  - `styles.css` — общие стили, адаптив, светлая/тёмная тема.
  - `script.js` — навигация, темы, эффекты, каталог игр.
  - `game-page.js` — игровой цикл для полноэкранной страницы.
  - `snake.js` — логика игры «Змейка».
  - `tetris.js` — логика игры «Тетрис».

Запуск
------

Бэкенд не требуется.

1. Открыть `index.html` в браузере (Chrome/Firefox/Edge, желательно последней версии).
2. Выбрать игру в блоке «Мини‑игры SyharikPlay».
3. Игра откроется в `game.html` в полноэкранном режиме.

Текущие игры
------------

### Змейка (`snake.js`)

- **Поле**: фиксированная сетка `20 x 20`.
- **Управление (ПК)**:
  - Стрелки или `WASD` (работает по `e.code`, не зависит от раскладки).
- **Управление (мобила)**:
  - Свайп по канвасу в сторону движения.
- **Особенности**:
  - Счёт + локальный рекорд (через `localStorage`).
  - Оверлей при поражении с подсказкой о перезапуске.
  - Цвет головы змеи зависит от темы (светлая/тёмная).

### Тетрис (`tetris.js`)

- **Поле**: `10 x 20`, классический набор фигур `I, J, L, O, S, T, Z`.
- **Управление (ПК)**:
  - `←` / `A` — влево.
  - `→` / `D` — вправо.
  - `↑` / `W` — поворот.
  - `↓` / `S` — ускоренный спуск (soft drop).
  - `Space` — жёсткий дроп до упора (hard drop).
- **Управление (мобила)**:
  - Свайп влево/вправо — сдвиг.
  - Свайп вниз — жёсткий дроп.
  - Короткий тап — поворот.
- **Особенности**:
  - Подсчёт очков + локальный рекорд (`localStorage`).
  - Превью следующей фигуры справа от поля (адаптивный размер).
  - Оверлей при поражении.
  - Цвет фона и сетки синхронизированы с текущей темой.

Глобальные особенности
----------------------

- **Тема**:
  - Светлая/тёмная, хранится в `localStorage` (`theme`), переключатель в шапке.
  - Игровые канвасы используют `--bg-secondary` и подстраиваются под тему.
- **Полноэкранная страница игры**:
  - Одинаковый контейнер и HUD для всех игр (`game.html` + `game-page.js`).
  - Пауза останавливает и логический апдейт, и обработку ввода (клавиатура/тач).
- **Мобилки**:
  - Вёрстка заточена под вертикальный экран.
  - Свайпы на канвасе отключают прокрутку страницы во время жеста.

Планы
-----

Кратко по приоритетам.

1. **Новые игры**
   - Реализовать `Flappy Bird` в `flappy-bird.js` (тач/пробел для прыжка, счёт по пройденным трубам).
   - Реализовать «Пятнашки» (`15 Puzzle`) в `fifteen.js` с адаптивным размером плиток.
2. **Общий игровой каркас**
   - Вынести общие типы/хелперы для игр (управление вводом, UI‑API, работа с рекордами) в отдельный модуль.
   - Унифицировать подсказки управления (ПК/мобила) на основе метаданных игры.
3. **UX/визуал**
   - Добавить мягкие звуки (действия, поражение, рекорд) с возможностью отключения.
   - Небольшие анимации появления/исчезновения оверлеев (поражение, пауза).
4. **Игровые фичи**
   - Для тетриса: настраиваемая скорость, счёт уровней, опция «быстрая новая партия».
   - Для змейки: режимы сложности (скорость, размер поля), опциональные «проходы» через стены.
5. **Техдолг**
   - Лёгкая типизация и структурирование кода игр (минимум — JSDoc/комментарии по входам/выходам).
   - Чистка и группировка CSS по блокам (layout / эффекты / игры).
